# Bangumi → Notion 同期

[English](README.en.md) | [简体中文](README.md) | 日本語

[Bangumi](https://bgm.tv) の作品ページでアニメの視聴ステータスや視聴話数を記録すると、その内容と日付を Notion データベースへ自動で同期するユーザースクリプトです。

- **一方向同期**：Bangumi から Notion へ書き込むだけで、Bangumi 側は変更しません。
- **手入力を上書きしない**：Notion に既にある項目は、ステータス・総話数・視聴話数を更新し、そのほかのプロパティは空のときだけ補完します。自分で入力した評価・コメント・日付はそのまま残ります。
- **トークンをコードに書かない**：初回利用時に設定パネルで入力し、ローカルのスクリプトマネージャーにのみ保存されます。

## インストール

1. スクリプトマネージャーをインストール：[Tampermonkey](https://www.tampermonkey.net/) または [Violentmonkey](https://violentmonkey.github.io/)。
2. [bangumi-notion-sync.user.js](bangumi-notion-sync.user.js) をインストール。
3. 下記の手順で Notion データベースと 2 つのトークンを用意します。

## 準備

### 1. Notion データベース

以下のプロパティを持つデータベースを作成します。名前と種類を一致させてください。列名が異なる場合は、スクリプト内の `CFG.PROP` を自分の列名に書き換えます。

| プロパティ名 | 種類 | 書き込む内容 |
| --- | --- | --- |
| Title | タイトル | 原題 |
| Alternative Title | テキスト | 中国語タイトル |
| Status | セレクト | Plan to Watch / Watching / Completed / On-Hold / Dropped |
| Episodes | 数値 | 総話数（本編のみ、SP を除く） |
| Episodes Watched | 数値 | 視聴済み話数 |
| Rating | テキスト | Bangumi でつけた評価 |
| Start Date | 日付 | 視聴開始日 |
| Finish Date | 日付 | 視聴完了（または一時中断・視聴中止）日 |
| Aired | 日付 | 放送日 |
| Bangumi | URL | 作品ページのリンク（重複チェックに使用） |
| Comment | テキスト | 自分のコメント |
| Cover | ファイル&メディア | カバー画像 |

### 2. Notion インテグレーション

1. [notion.so/my-integrations](https://www.notion.so/my-integrations) を開き、内部インテグレーションを作成してトークン（`ntn_` で始まる）をコピーします。
2. 上記のデータベースを開き、右上の `···` → **コネクト（Connections）** からこのインテグレーションを追加します。
3. データベース ID をコピー：ブラウザでデータベースを開き、URL の `?v=` の前にある 32 文字の文字列が ID です。

### 3. Bangumi トークン

1. [next.bgm.tv/demo/access-token](https://next.bgm.tv/demo/access-token) でアクセストークンを生成します。
2. 自分の Bangumi ユーザー名または UID を控えておきます。

### 4. 初回実行

スクリプトの画面表示は中国語です。以下では中国語の表記のあとに意味を添えています。

bgm.tv の任意の作品ページを開き、右下の **「同步到 Notion」**（Notion に同期）をクリックします。表示された設定パネルに Notion トークン、データベース ID、Bangumi トークン、Bangumi ユーザー名を入力し、「保存并同步」（保存して同期）をクリックします。値をコピーするために別のタブへ切り替えてもパネルは消えません。各トークン欄の横には「去获取」（取得する）リンクがあります。

あとで設定を変更・削除するには、ブラウザのスクリプトマネージャーのアイコンをクリックし、メニューから **「设置 Token / 数据库」**（トークン / データベースを設定）または **「清除已保存的 Token」**（保存したトークンを削除）を選びます。

## 同期のタイミング

| タイミング | 動作 |
| --- | --- |
| 作品ページを開いたとき | 1 回チェック |
| ページ上でクリックしてから 2 秒後 | 1 回チェック |
| このタブに戻ったとき | 1 回チェック。アプリや他の端末で変更した内容はここで反映されます |
| 「同步到 Notion」をクリック | 強制同期 |

自動チェックでは、視聴ステータス・評価・視聴話数・コメントのいずれかが変わったときだけ Notion に書き込みます。

> **注意：** スクリプトがある作品を初めて見たときは、現在の状態を記録するだけで同期しません。インストール前から記録済みの作品は、一度ボタンを手動でクリックしてください。

## 同期ルール

Bangumi の表記はサイト上の中国語のまま記載しています。

| Bangumi での操作 | Notion に未登録 → 新規作成 | Notion に登録済み → 更新 |
| --- | --- | --- |
| 想看（見たい） | Status = Plan to Watch | Status を更新 |
| 在看（見てる） | Status = Watching、Start Date を記入 | Status を更新。Start Date は空のときだけ記入 |
| 看过（見た） | Status = Completed、視聴話数を総話数に、Start / Finish Date を記入 | Status と視聴話数を更新。日付は空のときだけ記入 |
| 搁置 / 抛弃（一時中断 / 視聴中止） | 「看过」と同じ。ただし視聴話数は実際の値 | 同左 |
| 話数にチェック | 現在の状態で新規作成 | Episodes Watched を更新 |
| （放送中に総話数が確定するなど、Bangumi 側で総話数が変わった場合） | — | Episodes を更新 |
| 評価・コメントをつける | Rating / Comment に書き込み | 空のときだけ記入。既存の値は変更しない |
| 視聴ステータスを解除 | — | 既定では通知のみ。Notion の項目をゴミ箱へ移す設定も可能 |

既存の項目を更新すると、通知バーに変更内容が 1 行ずつ表示されます。例：「状态:Watching → Completed」（ステータス）、「进度:11 → 12/12」（視聴話数）、「补完成日期:2026-11-04」（完了日を補完）。

**総話数**：Bangumi で公表された話数を優先します。話数が不明（`*` 表示）の場合は、現在登録されている本編の話数を暫定値として使い、SP・OP・ED などは含めません。新規作成・既存項目の更新ともに同じルールを適用します。総話数が不明で本編も未登録の場合や、話数の取得に失敗した場合は、総話数を書き込みません。そのため、新規項目では空欄のままにし、既存項目では現在の値を保持します。ステータスと実際の視聴話数は通常どおり同期します。次回の自動チェックで、総話数の取得を再試行します。

**空のプロパティの補完**：既存の項目で Title・Alternative Title・Rating・Comment・Aired・Cover が空の場合、新規作成時と同じルールで補完します。既存の値は上書きしません。`SET_PAGE_COVER` が有効なときは、空のページカバーも補完します。プロパティの値を消しても、次回の同期で再び補完されます。

**重複チェック**：まず Bangumi のリンクで完全一致を探します。見つからなければタイトルで探します（Title が原題と一致、または Alternative Title が中国語タイトルと一致）。タイトルでの検索は Bangumi のリンクが空のページだけが対象なので、別の作品にリンク済みの同名ページ（リメイク版など）を取り違えることはありません。タイトルで一致した既存の項目には、Bangumi のリンクも補完されます。タイトルで複数のページが一致した場合は何も書き込まず、該当ページにリンクを手動で入力するよう通知します。

**日付**：

- **Start Date**：最初に「看过」をつけた話の日付を使います。それが取得できない場合、劇場版などの単話作品は当日、複数話の作品は既定で空欄のままにします。
- **Finish Date**：同期した日の日付です。アプリで「看过」をつけて、数日後に Web でその作品ページを開いた場合は、開いた日が Finish Date になります。
- **タイムゾーン**：すべての日付は `TIMEZONE`（既定は `Asia/Tokyo`）で換算します。bgm.tv は UTC+8 で表示するため、深夜にチェックした話は Notion では翌日になることがあります。

## 設定

スクリプト冒頭の `CFG` で調整できます：

| 設定項目 | 既定値 | 説明 |
| --- | --- | --- |
| `ON_EXISTING` | `'advance'` | 既存の項目の扱い：`'advance'` はステータス・総話数・視聴話数を更新し空のプロパティを補完、`'skip'` は一切触らない |
| `DELETE_BEHAVIOR` | `'ignore'` | 視聴ステータス解除時：`'ignore'` は通知のみ、`'archive'` はゴミ箱へ移動 |
| `START_DATE_FALLBACK_TODAY` | `false` | 開始日が推定できないときに当日を入れるか |
| `TITLE_GUARD` | `true` | リンクで一致しないとき、タイトルでも重複チェックするか |
| `ONLY_ANIME` | `true` | アニメ作品のみ同期 |
| `SET_PAGE_COVER` | `false` | カバー画像を Notion ページ上部のカバーにも設定するか |
| `TIMEZONE` | `'Asia/Tokyo'` | 日付換算に使うタイムゾーン |
| `PROP` | — | Notion プロパティ名の対応表 |

## よくある質問

**記録したのに同期されない？**
スクリプトがその作品を初めて見たため、状態を記録しただけの可能性が高いです。「同步到 Notion」を一度クリックしてください。

**「Notion 找不到这个数据库」（データベースが見つからない）と表示される？**
データベース ID と、インテグレーションがデータベースのコネクトに追加されているかを確認してください。

**「写入 Notion 失败(400)」（書き込み失敗）と表示される？**
多くはプロパティ名や種類の不一致です。上の表と照らし合わせてください。

**トークンが無効と表示される？**
トークンを再生成し、スクリプトメニューの「设置 Token / 数据库」から更新してください。

**Bangumi で評価を変えたのに Notion が変わらない？**
仕様です。既存の項目の Rating / Comment は空のときだけ補完し、既存の値は Notion 側で自分で管理する想定のため上書きしません。

**「Notion 里有多条同名且没填链接的页面」（リンク未入力の同名ページが複数ある）と表示される？**
タイトルで複数のページが一致し、どれが正しいか判断できません。該当ページの Bangumi プロパティに作品のリンク（例：`https://bgm.tv/subject/12345`）を入力してから、もう一度「同步到 Notion」をクリックしてください。

## プライバシー

- トークン、データベース ID、ユーザー名はローカルのスクリプトマネージャーのストレージにのみ保存され、スクリプトのコードには書き込まれません。
- スクリプトがアクセスするのは `api.bgm.tv` と `api.notion.com` のみです。
